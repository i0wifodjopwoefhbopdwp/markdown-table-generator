# Markdown Table Generator

Расширение для VS Code, которое создаёт таблицы Markdown.

Автор: Запрудина Екатерина Викторовна, группа М3117.

При разработке использован ИИ для подготовки кода.

## Возможности

- Ввод названий столбцов через запятую.
- Создание от 1 до 100 пустых строк.
- Проверка пустых названий и запрет символа | в заголовках.
- Проверка количества строк.
- Вставка таблицы на место курсора.
- Отмена ввода без изменения документа.

## Запуск

1. Открыть папку проекта в VS Code.
2. Нажать F5 или Fn + F5 на Mac.
3. В открывшемся окне Extension Development Host открыть
   текстовый файл и поставить курсор на отдельную пустую строку.
4. Открыть палитру команд: Cmd + Shift + P на Mac.
5. Выбрать «Markdown: Создать таблицу».
6. Ввести названия столбцов через запятую.
7. Ввести количество строк от 1 до 100.

Для корректного отображения таблицы рекомендуется файл .md.
Предпросмотр Markdown на Mac открывается через Cmd + Shift + V.

## Пример

Названия столбцов: Название, Описание.
Количество строк: 2.

Результат:

```markdown
| Название | Описание |
| --- | --- |
|  |  |
|  |  |
```

## Устройство проекта

- package.json — описание расширения и объявление команды.
- extension.js — обработка ввода и генерация таблицы.
- .vscode/launch.json — настройка запуска для отладки.

## Логика работы

Функция activate регистрирует команду markdownTable.generate.
При её вызове расширение проверяет наличие открытого редактора,
запрашивает заголовки и количество строк.

Заголовки разбиваются по запятым и сохраняются в массив.
Функция createTable формирует заголовок, строку разделителей
и пустые строки с помощью массива и цикла.
Готовая таблица вставляется в документ через VS Code API.

При неверном вводе показывается сообщение с пояснением.
При отмене любого поля документ не изменяется.

## Ограничения

Запятая используется как разделитель названий столбцов.
Символ | в заголовках не допускается.
Расширение создаёт пустую таблицу; данные пользователь заполняет сам.
